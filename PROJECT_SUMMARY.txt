================================================================================
WHAT THIS PROJECT DOES
================================================================================

CodeClone detects code plagiarism using Abstract Syntax Tree (AST) analysis
to identify structural similarities even when code has been superficially
modified (renamed variables, reordered functions, changed comments).

PROBLEM SOLVED:
Traditional plagiarism detectors fail when students/developers rename variables
and functions. CodeClone analyzes the underlying STRUCTURE and LOGIC of code,
not just text matching.

================================================================================
TECHNICAL IMPLEMENTATION
================================================================================

Core Algorithm:
1. Parse Python code into Abstract Syntax Tree (AST)
2. Extract structural features:
   - Function signatures (param count, return patterns, nesting depth)
   - Control flow patterns (if/for/while structures)
   - Operation sequences (ADD, MULTIPLY, COMPARE operations)
   - Variable relationship graphs

3. Normalize features to be name-independent
4. Compare using multi-dimensional similarity scoring:
   - Function Structure (35% weight)
   - Control Flow Logic (30% weight)
   - Operation Patterns (25% weight)
   - Exact Structure Match (10% weight)

5. Generate verdict based on weighted overall score

Key Classes:
- CodeStructureExtractor: Parses and extracts normalized features
- SimilarityCalculator: Computes multi-dimensional similarity
- PlagiarismDetector: Main interface for analysis

================================================================================
HOW TO RUN
================================================================================

Requirements: Python 3.6+ (uses ONLY standard library - no pip installs!)

1. Command-line demo:
   python run_demo.py

2. Generate HTML reports:
   python generate_report.py
   (Then open .html files in browser)

3. Use programmatically:
   from code_analyzer import PlagiarismDetector
   detector = PlagiarismDetector()
   result = detector.analyze_pair(code1, code2)
